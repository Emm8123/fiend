# Fiend — Sistema de Servicios Local

Sistema de gestión de clientes y servicios (tareas universitarias) **100% offline**.

## Características

- **Dashboard** minimalista con estadísticas
- **Clientes**: agregar, editar, buscar (estudiantes, universidad, contacto)
- **Servicios / Tareas**: estados Pendiente → En proceso → Listo → Entregado
- **Facturas**: generar, visualizar e imprimir/PDF (desde el navegador)
- Datos guardados en **localStorage** del dispositivo (sin servidor ni MySQL)
- Diseño oscuro, limpio y responsive (iPhone / Android / desktop)
- Exportar backup JSON
- Instalable como PWA (añadir a pantalla de inicio)

## Cómo usar

1. Abre `index.html` en cualquier navegador (Chrome, Safari, Firefox).
2. En el móvil: abre el archivo o usa GitHub Pages, luego **“Añadir a pantalla de inicio”**.
3. Todo funciona sin internet una vez cargado.

## Demo en vivo (GitHub Pages)

Una vez habilitado Pages: https://emm8123.github.io/fiend/

## Datos

- Todo se guarda localmente en el navegador.
- Usa el botón de exportar (arriba a la derecha) para respaldar.
- Los datos **no se borran** al cerrar la app, solo si borras los datos del navegador o desinstalas.

## Notas

- Para facturas: al ver una factura, usa "Imprimir / PDF" → el navegador permite guardar como PDF.
- No requiere base de datos, servidor ni conexión.
- Ideal para freelancers de servicios académicos / tareas universitarias.

Hecho con ❤️ para uso local.
